3. Generate, iterate with "Ask for changes" until happy
4. Share the Figma URL with Claude for SVG extraction via MCP

## Winning Prompt Template

Every prompt follows this structure that produced the Mini Meowww result:

```
Design a mascot character — a [DESCRIPTION] — for a mobile app. Think Duolingo's Duo owl level of character design: a MEMORABLE CHARACTER with personality, not just shapes assembled into a cat.

**Character: [NAME]** — [BACKSTORY/PERSONALITY HOOK]

- [COLOR AND PATTERN DETAILS]
- [EYE DETAILS — always emphasize these]
- [FACE DETAILS]
- [UNIQUE FEATURES]
- [BODY TYPE AND BUILD]

**Character design direction:**
- DISTINCTIVE SILHOUETTE — recognizable even as a shadow
- Every curve should express personality
- Posture should convey [PERSONALITY TRAIT]
- Style reference: Duolingo Duo, Genshin Impact chibi art, mobile game mascots
- Flat 2D vector illustration, cel-shaded, clean edges
- Should look like merch material — stickers, pins, plushies

**SVG groups:** tail, body, head, ears, face
```
